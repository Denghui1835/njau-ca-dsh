# 纳新宣讲

> 讲这场的人通常是会长或部长。
> 全场只有一句话要让人记住：**「我零基础来了也能学到东西，而且不会被晾着。」**
> 新生最怕的不是难，是「去了没人管」。

## 1. 封面
- 页面元素：协会全称、届次（如「2026 年秋季招新」）、一句话口号、协会标识
- 怎么讲：**不要念标题**。用一个问题开场，比如「在座有多少人电脑里装过 Python？举个手。」
- 素材来源：协会标识文件；往届 PPT 封面可直接复用改届次

## 2. 我们是谁
- 页面元素：协会全称与简称、成立时间、指导单位、会徽
- 怎么讲：一句话讲清定位，别念章程。重点是「我们是干什么的社团」，不是「我们的组织架构」
- 素材来源：协会章程（知识库）、`docs/` 里的协会简介

## 3. 我们在做什么
- 页面元素：4 张图（算法竞赛 / 软件开发 / 网络安全 / 人工智能），每个配一行说明
- 怎么讲：**这是新生最关心的一页**。说清楚「协会平时真的在干这些事」，不是只有名字
- 素材来源：往届活动照片、集训记录

## 4. 我们做出过什么
- 页面元素：竞赛获奖列表（赛事名 + 奖项 + 年份）、代表性项目截图
- 怎么讲：**只放真的**。没有的就跳过这一页，不要编。新生会去查
- 素材来源：竞赛记录、获奖证书照片

## 5. 我们平时怎么玩
- 页面元素：活动照片墙（3-6 张）、每周例行活动时间地点
- 怎么讲：让新生看到「这里有人一起玩」。氛围比成绩更能打动人
- 素材来源：活动照片、例会记录

## 6. 你能得到什么
- 页面元素：四栏——技能 / 竞赛机会 / 项目经历 / 一群人
- 怎么讲：把「能得到什么」讲成**具体的事**：「一学期后你能自己写出一个小网站」，而不是「提升自我」
- 素材来源：往届成员的成长路径（可问老成员要例子）

## 7. 我们怎么带你
- 页面元素：培养路径图（零基础 → 入门 → 能参赛 → 能带队）
- 怎么讲：**这一页决定报名率**。明确说：有学长带、有学习路线、有集训
- 素材来源：学习路线（`learning` 域）、集训安排

## 8. 招新要求
- 页面元素：招哪些方向、各招几人、报名截止时间、报名方式、面试安排
- 怎么讲：**必须非常具体**。「不限基础」要说出来。二维码要清晰可扫
- 素材来源：本年度招新计划（`recruit` 域）

## 9. 常见问题
- 页面元素：3-5 个问答（零基础能来吗 / 会不会很忙 / 要交钱吗 / 大一能参加竞赛吗）
- 怎么讲：主动回答新生不好意思问的问题。**「要不要交钱」一定要正面回答**
- 素材来源：往届新生提问记录

## 10. 联系方式与结束
- 页面元素：招新群二维码、公众号、负责人联系方式、一句话收尾
- 怎么讲：结尾留时间提问。**把二维码留在屏幕最久**，散场前别急着关
- 素材来源：招新群二维码（每年更新）

## 讲之前检查
- [ ] 时间地点确认了吗
- [ ] 二维码是最新的吗（旧群二维码扫不进是最常见事故）
- [ ] 有没有拿不准的数据（获奖、人数）——**拿不准就不讲**
- [ ] PPT 在宣讲场地的电脑上能打开吗（字体、版本）
