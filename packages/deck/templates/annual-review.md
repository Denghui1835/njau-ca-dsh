# 年审汇报

> 这是**交材料**的 PPT，不是宣传 PPT。评审要看的是「这个社团合规、活跃、账目清楚」。
> 全程一个原则：**能对上账、能查到记录**。
> 相关插件：`school`（年审材料自动填充）。本模板定义结构，数据由那个插件准备。

## 1. 封面
- 页面元素：协会全称、学年（如「2026–2027 学年」）、汇报人、日期
- 怎么讲：照着念就行，这页不出彩也没关系
- 素材来源：协会全称与届次（`org` 域）

## 2. 协会概况
- 页面元素：全称、成立时间、指导单位、现任负责人、会员人数、部门设置
- 怎么讲：**人数要能对上名单**。评审会拿这个数跟备案比
- 素材来源：会员名单（`org` 域）、章程

## 3. 组织建设
- 页面元素：换届情况、部门架构图、例会频次、制度建设
- 怎么讲：重点说**换届是否规范**（这是年审常查项）
- 素材来源：换届记录、例会记录（`org` / `report` 域）

## 4. 本年度活动总览
- 页面元素：一张表——活动名称 / 时间 / 类型 / 参与人次
- 怎么讲：**用表格，别用图**。评审要的是可核对的清单
- 素材来源：活动台账（`events` 域）

## 5. 重点活动详述
- 页面元素：挑 2-3 个活动，每个一页：背景 / 内容 / 成效 / 照片
- 怎么讲：选**有记录、有照片、有数据**的。宁可少讲，不要讲不实的
- 素材来源：活动总结、照片（`events` / `media` 域）

## 6. 竞赛与成果
- 页面元素：获奖清单（赛事 / 奖项 / 时间 / 获奖人）、项目成果
- 怎么讲：**只列能拿出证书的**
- 素材来源：竞赛记录（`learning` 域）

## 7. 财务管理
- 页面元素：收入明细、支出明细、结余、票据情况
- 怎么讲：**这一页最容易被查**。数字必须跟票据对上。
  社团**不得从事商业经营、不得作为经营主体**（见 `GOVERNANCE.md` 红线）
- 素材来源：报销台账（`finance` 域）

## 8. 宣传与影响
- 页面元素：宣传渠道、发布条数、阅读量、媒体报道
- 怎么讲：**如实报**。新媒体账号数量与备案情况是年审敏感项，多开的号要说明
- 素材来源：宣传记录（`media` 域）

## 9. 不足与改进
- 页面元素：2-3 条坦白的不足 + 对应改进措施
- 怎么讲：**要写**。一条不足都不写反而不可信
- 素材来源：年度总结、成员反馈

## 10. 下一年度计划
- 页面元素：拟办活动、拟参加竞赛、组织建设目标
- 怎么讲：计划要**具体可考核**，别说空话
- 素材来源：理事会讨论记录

## 交之前检查
- [ ] 财务数字和票据对得上吗
- [ ] 活动清单和台账对得上吗
- [ ] 会员人数和名单对得上吗
- [ ] 有没有提到任何商业合作、收费项目（**红线，必须删**）
- [ ] 新媒体账号都在备案范围内吗
- [ ] 文件名和格式符合学校要求吗
