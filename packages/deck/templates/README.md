# 演示模板怎么加 / 怎么改

这个目录里的每个 `.md` 就是一个演示模板，`deck` 插件启动时会自动扫进来。

**改模板不需要写代码，也不需要重启 DSH 之外的任何东西** ——
改完文件，下次 `dsh njau` 启动就是新版。这就是「制度改得比代码勤」的应对方式。

## 文件格式

```markdown
---
id: recruit                       # 唯一标识，命令行和工具里用它
name: 纳新宣讲                     # 给人看的名字
use: 招新季面向新生的宣讲会          # 什么时候用
duration: 15-20 分钟               # 大概讲多久
required: 封面 / 我们是谁 / 联系方式  # 必备页，用 / 分隔
---

# 纳新宣讲

## 1. 封面
- 页面元素：……
- 怎么讲：……
- 素材来源：……

## 2. 我们是谁
……
```

要点：

- 页序写成 `## N. 标题`；`##` 和 `###` 都认，但 `#` 是文档标题、不算页
  （编号后的分隔符：半角点 `.`、全角点 `．`、顿号 `、` 都认）
- frontmatter 只支持 `key: value` 单行，**不引入 YAML 依赖**
- 正文随便写，`deck` 会把全文原样交给 agent
- 不编号的二级标题（比如 `## 讲之前检查`）不会被当成页，可以放心当小节用

## 加一个新模板

1. 在这个目录里新建 `<id>.md`
2. 按上面的格式写 frontmatter 和页序
3. 跑 `njau_deck_templates` 确认被扫到了，**并且页数不是 0**

> 页数是 0 就说明页标题的写法没被认出来 —— 见上面「要点」第一条。

## 改模板的红线

- **不要写编造的数据**（获奖、人数、金额）。模板是给人照着填的，
  里面出现的数字要么是占位符，要么是真实的历史数据
- **不要加入商业合作、收费、赞助相关的内容**（见 `GOVERNANCE.md` 第五节）
- 年审、立项这类要交给学校的模板，**措辞要跟学校现行规定一致**，
  拿不准就去问指导老师，不要自己发明说法

## 为什么模板放在插件里而不是数据目录里

模板是**制度**，数据是**今年的情况**。

- 模板跟着插件走 → 装到哪台机器上都有，换届时随仓库一起传下去
- 数据放在 `~/.dsh/njau-ca/deck/` → 每年不同，不进 git

`templatesDir` 可以在 `cordis.patch.yml` 里覆盖，指向协会自己的模板目录。
