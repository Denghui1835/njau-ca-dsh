# 活动立项答辩

> 这是**要审批**的 PPT。审批人关心三件事：
> **安全吗？要多少钱？出了事谁负责？**
> 每一页都该在回答这三个问题之一。
> 相关插件：`school`（社团管理系统表单填充）。本模板定义说什么，
> **但绝不代填学校系统的表单** —— 表单由人登录、人提交（见红线）。

## 1. 封面
- 页面元素：活动名称、主办社团、拟办时间、汇报人
- 怎么讲：直接进入正题
- 素材来源：活动策划书

## 2. 活动背景与目的
- 页面元素：为什么办、面向谁、想达到什么效果
- 怎么讲：**不要说「丰富校园文化」这种空话**。说具体的：让多少人学到什么
- 素材来源：活动策划书（`events` 域）

## 3. 活动基本信息
- 页面元素：名称 / 时间 / 地点 / 对象 / 预计规模 / 活动类型
- 怎么讲：**必须全部确定**。时间地点没定就别来答辩
- 素材来源：场地申请结果、活动策划书

## 4. 活动流程
- 页面元素：时间轴——几点到几点做什么
- 怎么讲：精确到半小时。审批人会看有没有空档、有没有超时风险
- 素材来源：活动流程表

## 5. 人员分工
- 页面元素：总负责人、各组负责人、职责
- 怎么讲：**每个环节都要有具体的人**。「大家一起来」是不合格的回答
- 素材来源：工作组名单

## 6. 经费预算
- 页面元素：预算表（项目 / 单价 / 数量 / 金额 / 备注）、合计、经费来源
- 怎么讲：**数字要经得起问**。经费来源要合法：
  会费、学校支持可以；**商业赞助、收费活动不行**（见红线）
- 素材来源：预算表（`finance` 域）

## 7. 风险与预案
- 页面元素：风险清单（天气 / 人数超预期 / 设备故障 / 安全） + 每条的应对
- 怎么讲：**这一页是加分项**。说明你想过坏情况
- 素材来源：往届活动踩过的坑

## 8. 预期成果
- 页面元素：参与人数、产出物、后续影响
- 怎么讲：给可考核的指标。活动结束后要能拿这个对照
- 素材来源：活动策划书

## 9. 请示事项
- 页面元素：需要审批什么（场地 / 经费 / 时间 / 宣传）
- 怎么讲：**明确列出来**，别让审批人猜你要什么
- 素材来源：—

## 答辩前检查
- [ ] 时间地点定了吗
- [ ] 预算算对了吗（自己核算一遍）
- [ ] 经费来源合规吗（**不能有商业赞助**）
- [ ] 安全预案有没有（尤其户外、用电、人数多的活动）
- [ ] 有没有需要学校系统填报的表单 —— **那是人工步骤，不自动提交**
